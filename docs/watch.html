CP-Agent: Ask a model for the next step, run the Python it writes, feed the output back, stop when it says it is done. In this case, CP-Agent runs in µNorman against Claude Sonnet 5 and a Python process.

1. A problem it solves in one step

Task: What is the sum of all multiples of 3 or 5 below 1000?

┌─ sum of multiples of 3 or 5 below 1000
│  ask   step     469 in    50 out   $0.001438    182ms → 2845ms   ok
│  call  py/exec     0 in     0 out       $0.00   2845ms → 2916ms   ok
│  ask   step     524 in    24 out   $0.001288   3037ms → 4695ms   ok
│
│  2 model calls, 1 kernel calls
│  spent $0.002726 of the $0.50 budget in 4695ms
└─ answer: "233168"

The model wrote Python, the kernel ran it, and the output came back as the next message in the context. Note the shape of the second ask: 524 input tokens against the first one's 469, because the conversation grew by the code and its output.

2. A problem that needs it to check its own work

Task: A farmer has chickens and cows, 30 heads and 74 legs. How many of each? Work it out with code and check your answer.

┌─ chickens and cows
│  ask   step     489 in   130 out   $0.002278    150ms → 3336ms   ok
│  call  py/exec     0 in     0 out       $0.00   3336ms → 3425ms   ok
│  ask   step     598 in    65 out   $0.001846   3525ms → 4929ms   ok
│
│  2 model calls, 1 kernel calls
│  spent $0.004124 of the $0.50 budget in 4929ms
└─ answer: "7 cows and 23 chickens (7*4+23*2=74 legs, 7+23=30 heads)."

3. The same agent, given less money than it needs

The identical program and problem, under a cap of $0.002 instead of $0.50.

┌─ the same task, capped at $0.002
│
│  0 model calls, 0 kernel calls
│  spent $0.00 of the $0.50 budget in 188ms
└─ failed: OverBudget

   the cap held: spent $0.00 of $0.002

Zero model calls, and nothing spent. Before any call, ask reserves the worst case — the input it is about to send, plus the largest answer the type allows, plus the thinking allowance. That reservation did not fit $0.002, so the model was never contacted. The agent did not start and fail partway; it refused to start.

This is the one claim on this page that a hand-written agent script cannot make. A budget in a library is a counter somebody remembers to check. Here it is enforced before the money is spent, on every effect, with no way around it — the program has no door to the outside except ask and call.

The same program, running here

The source below is the one that produced those traces. The only difference is the host: live, a real model and a real Python process; here, a script and a simulated clock. Press Run — this executes in your browser, free and offline.

cp-agent.nrm 
(grant claude (model))                       ; defaults: Claude Sonnet 5
(grant py     (kernel [exec (Text 4000)]))   ; a real Python process in live mode

(datatype Step
  [Exec (code (Text 2000))]      ; "run this and show me the output"
  [Done (answer (Text 500))])    ; "this is my final answer"

;; A tool error becomes an observation the model can read. Nothing else does:
;; running out of money is not something to explain to a model.
(define observe (k code)
  (catch (call k exec code) e
    (case e [(ToolError m) m] [_ (fail e)])))

(define react (model k ctx fuel)
  (if (<= fuel 0)
      (fail 'out-of-fuel)
      (case (ask model Step ctx 'step)
        [(Exec code)
           (react model k
                  (append ctx (list (Message [role Assistant] [content (show (Exec code))])
                                    (Message [role Tool]      [content (observe k code)])))
                  (- fuel 1))]
        [(Done answer) answer])))

(define cp-agent (model k task)
  (budget ([cost $0.50] [time 5min])
    (react model k (list (Message [role User] [content task])) 8)))

;; Scripted, the model and kernel are canned, so this is exact and free.
(script solving
  [step    (reply "{\"tag\":\"Exec\",\"code\":\"print(sum(range(101)))\"}") (out 20) (latency 3s)
           (reply "{\"tag\":\"Done\",\"answer\":\"5050\"}")                 (out 12) (latency 2s)]
  [py/exec (result "5050") (latency 1s)])

(under ([script solving] [cost $1.00] [time 5min])
  (check-expect (cp-agent claude py "What is the sum of 0 to 100?") "5050")
  (check-within (cp-agent claude py "What is the sum of 0 to 100?") ([time 6s])))

;; A kernel error is not a crash: the message goes back to the model.
(script recovering
  [step    (reply "{\"tag\":\"Exec\",\"code\":\"print(undefined_name)\"}") (out 20) (latency 2s)
           (reply "{\"tag\":\"Exec\",\"code\":\"print(42)\"}")             (out 18) (latency 2s)
           (reply "{\"tag\":\"Done\",\"answer\":\"42\"}")                  (out 12) (latency 2s)]
  [py/exec (error "NameError: name 'undefined_name' is not defined") (latency 1s)
           (result "42") (latency 1s)])

(under ([script recovering] [cost $1.00] [time 5min])
  (check-expect (cp-agent claude py "Print 42.") "42"))

What these runs show

  • A language cannot make a model smarter. Answer quality comes from the model and the prompt. CP-Agent's own paper found a 50-line prompt beat an 800-line one, and that imposing structure on the loop hurt. Scaffolding is not free.
  • Nothing here is cheaper or faster than the obvious alternative. What µNorman changes is that the cost is bounded in advance and recorded, not that it is lower.
  • The concurrency argument is untested here. µNorman's dataflow workflow finds the critical path — 40 seconds against 60 for the same four calls — but that is simulated. CP-Agent is sequential and exercises none of it.

The experiment that would settle it is a known one: port CP-Agent, run it against the Python original on a slice of CP-Bench, and measure task success, dollars per solved problem, and wall-clock time. That has not been done. Until it is, “µNorman improves performance” is a hypothesis, and this page is careful not to pretend otherwise.

What these runs do support is a narrower claim, and the one the project actually makes: µNorman does not make an agent better, it makes an agent's behaviour knowable and bounded.

Running it yourself

Local execution with the example file:

cargo run -- examples/cp-agent.nrm

Live, with ANTHROPIC_API_KEY set and Python on the PATH — a few cents:

cargo test --test live_cp_agent -- --ignored --nocapture

LIVE-SETUP.md covers getting a key and capping the spend.
